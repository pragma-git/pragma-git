Getting Started
===============

1) Drag Pragma‑git.app to Applications.
2) Launch Pragma-git.app.  If macOS blocks it (normal for internet downloads), go to System Settings → Privacy & Security and click Open Anyway. 
3) Launch the app again


Or step 2) Command‑line alternative :
    sudo xattr -r -d com.apple.quarantine /Applications/Pragma-git.app

(Removes the quarantine attribute macOS adds to downloaded packages)
