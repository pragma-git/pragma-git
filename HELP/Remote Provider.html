What is a Remote Provider

Github is a remote git-repository provider. There are other providers too, such as Gitlab, Bitbucket, and more. You may connect your local repository to a provider, and can use this as a backup, to keep different computers you work with in sync, or for cooperation with others.

About provider account

A remote provider requires a registered account (that is, a username and a password / access token). The location of the remote repository is defined by an URL, of a format similar to "https://github.com...". A new account can be created by following the link to "Register an account".

An access token can be defined from the provider's website, by following the link "Create an access token". The access token can act as a password for git operations, but also give access to operations such as creating a new repository from within Pragma-git.

For the provider Bitbucket, it is better to define an app-password instead of a token, which allows both git operations, and interacting with administrative tasks such as creating a new repository.

Fill in Account:

Username. Bitbucket is special, enter Bitbucket workspace-name instead.
A new account can be created by following the link to "Register account".

Access token. Bitbucket is special, enter username:app-password instead.
An access token / app-password can be defined from the provider's website, by following the link "Create an access token / app-password"
