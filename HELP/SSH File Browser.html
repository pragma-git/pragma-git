SSH Server File Browser

The SSH Server File Browser allows you to inspect and modify files directly in remote Git repositories hosted on an SSH server. It provides seamless, transparent editing by managing local temporary working copies and automatically syncing saved changes back to the remote server over SSH.

When is this window opened?

Clicking the Project folder icon () in the bottom titlebar of the main window when your active repository is located on an SSH server (ssh://...) opens this file browser. If you switch repositories to another SSH repository and click the folder icon again, a new window will open for that repository, cascaded down and to the right.

Navigation

  • Top Breadcrumb bar: Displays the full repository path from the repository root (🏠). Click any previous folder segment to jump straight to that folder. When deep inside nested folders, the path gracefully abbreviates intermediate segments (...) so the last item always remains visible.
  • Up button: Click the button on the right of the path bar (or double-click the .. row in the table) to go up one directory level.
  • Opening folders: Double-click any folder row in the table (or click the (open) link in the Action column) to navigate into that folder.
  • Refresh: Click the button below the table (or press Cmd+R on macOS / Ctrl+R on Windows/Linux) to reload the contents of the current remote directory.

Editing Files & Automatic Syncing

Pragma-git allows you to edit files on remote servers using local editors without manual transfer commands:

  1. Opening a file: Double-click a file (or click the (edit) link). Pragma-git securely downloads the file to an isolated local temporary folder and opens it in your configured editor.
  2. Watching changes: The opened file is added to the Open Files list at the bottom of the window, and a file watcher monitors your local copy.
  3. Automatic syncing on save: Whenever you save the file in your editor (Cmd+S / Ctrl+S), Pragma-git instantly detects the modification and uploads the updated content back to the SSH server. The live status changes to ✓ Synced HH:MM:SS, and Pragma-git's main window updates Git status and modified file counts.
  4. Focusing opened files: If a file is already open, clicking its path in the Open Files panel brings your editor back into focus.
  5. Stopping synchronization: Clicking the ✕ button next to a file in the Open Files list stops watching that file and removes it from the sync list.

Configuring the Editor

You can choose which editor Pragma-git uses to open remote files in Settings → Software → Git & system tools → Editor:

  • Empty (default): Opens the built-in pragma-merge editor in edit mode.
  • system: Uses your operating system's default application associated with that file type.
  • Custom command/app: Specify any custom code editor or command (e.g. code, subl, atom, gedit, or an app name).

Creating Files and Folders

Below the directory table, you have quick action buttons:

  • : Creates a new file in the currently viewed remote directory. You can choose whether to open it in your editor immediately.
  • : Creates a new subdirectory in the currently viewed remote folder.

Closing & Safety Warning

As long as the SSH Server File Browser window remains open, watchers keep syncing your saved changes.

If you close the file browser (or close Pragma-git itself) while one or more files are still open and being watched, Pragma-git will display a Warning dialog listing the active files. This gives you your last chance to save and close those files in your editor before automatic synchronization stops.
