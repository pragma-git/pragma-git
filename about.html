🚀 Getting Started with Pragma-git

Pragma-git is designed to make version control friendly, visual, and reliable. Whether you are an experienced developer or find traditional command-line Git overwhelming, Pragma-git keeps your work safe with an intuitive single-click mental model.

How to open your project
Drag and drop your project's folder directly onto the Pragma-git main window. If it's not yet a Git repository, Pragma-git will ask if you want to initialize it automatically.

🔄 Everyday Workflow

1. Write ongoing notes as you work
At any point while working, write thoughts, tasks, or bug IDs in the message scratchpad. Your notes stay preserved even when you switch branches, explore other repositories, or close the app.
2. Store your work snapshot
When you are done with a task, finalize your message and press . Pragma-git stages modified files, creates a Git commit, and automatically pushes to your remote server if auto-push is on.
3. Explore past history with arrows
Use the left ▼ down arrow to step back in time through historical revisions, and ▲ up arrow to go forward toward newer commits. When in historical mode, click ^HEAD in the top header to instantly return to HEAD and resume editing your active working notes.

Top Titlebar & Navigation

Repository Switcher Top Bar
Clicking the repository name opens the repository list menu. You can quickly switch between active projects or manage repository groups.
Branch Switcher Top Bar
Shows the active Git branch (for instance, main or develop). Click to switch to any local branch, fetch from remotes, or inspect branch statuses. Typically you can not switch branch when you have uncommitted files.
Continuous Integration (CI) Status Badge Live Pipeline Status
Monitors and displays live build & test results from GitHub Actions, GitLab CI, or Bitbucket Pipelines for the active commit.

Note: The CI pipeline state is communicated through distinct icon shapes:

Solid Rectangle (Passed): Continuous Integration tests completed successfully. Clicking the badge opens the pipeline run in your web browser.
Cracked / Fractured (Failed): Pipeline failed or reported errors. Click to inspect failed workflow logs in your web browser.
Dashed with Ellipsis (In Progress): Continuous integration build or test pipeline is currently pending / executing.
Personal Project Notes Tool
Opens the dedicated notebook for the active repository. Notes are stored locally in the .Pragma-git/Notes folder. Notes are not stored on the remote git server (to avoid leaks of sensitive information.)
Create New Branch Action
Creates and checks out a new branch from your current revision. Useful for starting experimental features or side-tracks without affecting your main work.
Merge Branches Action
Incorporates changes from another branch into your current branch. If conflicts occur, Pragma-git shows that there are conflicts in the lower part of the window. Click that text to open the conflict resolution tool to assist you.
Pull from Remote Action
Downloads the latest commits from your remote server (e.g., GitHub, GitLab) and merges them into your local branch.
Push to Remote Action
Uploads local commits to the matching remote branch. Active when auto-push is disabled in Settings, or after manual rebases. If auto-push is enabled (default) it shows that push to remote is ongoing.
Tag Revisions Action
Creates an alias or release marker (e.g., v1.0.0) pointing permanently to a specific commit.

Checkout any old tag: Opening the Tag Manager lets you inspect, search, and directly check out any existing tag to explore or build past released versions.

Message Area & Commit Flow

📝 Central Message Area (Two Operating Modes) Core Workflow
The central textarea operates in two distinctly different modes depending on whether you are at your Active Working State (HEAD) or browsing a Historical Commit:

1. Active Working State (at HEAD)

When working at HEAD, this box serves as your personal scratchpad and mental note memory. You can write your ongoing thoughts, plans, or next steps here as you work.

  • Persistent Per-Repository: Your draft notes stay saved specifically for this repository even if you switch branches, switch to other repositories, or restart Pragma-git.
  • Committing: When you are ready to snapshot your code, simply replace or refine your notes with your descriptive commit message (or stash name) and press Store.

2. Historical Commit Mode (Navigating Past Revisions)

When you navigate backward in git history using the ▼ (Down) arrow on the left, the message box becomes read-only and displays the permanent commit log message of that historical revision.

  • Navigating History: Use ▼ (Down Arrow) to navigate backward into past commits, and ▲ (Up Arrow) to step forward toward newer commits.
  • Returning to HEAD: When in historical mode, click main (where the current branch is shown in front of the symbol)
  • Double-Click to Edit (Amend): Double-clicking an existing historical commit message allows you to edit or amend the commit text.
Store Commit & Push (or Checkout) Primary Action
The primary action button on the right adapts to your current context:
  • At Working State (HEAD): Stages all modified and new files, creates a new commit using the text in the message area, and pushes to remote.
  • When Historical Commit is Selected: Changes to Checkout, allowing you to view and test that past point in time.
Store in same (Amend Last Commit) Option
Check the " Store in same" check-box to combine newly modified files into the most recent commit instead of creating a brand new commit.
Double-click to change (Rewrite Commit message) Option
Rewrite commit message for latest commit (not shown in preview above). It comes with a warning if you auto-push to a remote repository, since it changes history.
Find in History (Search) Search Tool
Clicking the magnifying glass in the left navigation column opens or collapses the Find Toolbar directly above the status bar:
  • Search Commit Messages or Code Changes: Toggle between searching through commit log messages or searching through actual diff code changes.
  • File Pattern Filtering: Narrow your search down to specific files or path patterns.
  • Date Range: Optionally specify After and Before dates to filter commits within a given time window.
  • Step Through Results: Navigating results lets you browse matching past commits instantly.

Bottom Bar Tools & Status

Project Folder Bottom Tool
Opens your project folder directly in Finder (macOS) or Explorer (Windows).
Command Line Terminal Bottom Tool
Launches your native system terminal with the current working directory preset to the repository folder.
Modified = 2 | New = 0 | Deleted = 0 Modified Files List & Tools Working Tree Status
Shows the live count of modified, new (untracked), and deleted files in your project. Clicking this label opens the Changed Files Window with interactive diff viewers, selective file staging checkboxes. In history browsing mode, it shows the number of modified files etc compared to previous commit.
Commit Graph Visualizer
Opens the visual commit history graph showing branch lanes, merges, stash points, and commit ancestry across the entire project.
Mark / Pin Commit Comparison
Pins the historical commit, so that the modified file count and diff viewers compare to this reference point.
#a1b2c3d Commit Hash Identifier Revision Reference
Displays the short SHA-1 hash of the currently selected commit.
  • Click: Copies the 7-character short hash to your clipboard.
  • Shift + Click: Copies the complete 40-character full git commit-hash.
  • Comparison Mode: When a commit is pinned, this field indicates which commit your working files are currently being compared against.
Revert Commit Action
Creates an inverse commit that undoes the changes introduced by the selected historical revision without destroying git history.
Cherry-pick Action
Applies the specific changes from an individual commit on another branch directly onto your current branch.
Stash & Stash Pop Temporary Storage
Temporarily shelve uncommitted work without making a permanent commit:
  • Stash: Shelves your modified files to a temporary stack and reverts your working directory to a clean HEAD state.
  • Stash Pop: Restores your most recently shelved stash changes back into your working tree.
Settings Window Configuration
Manage repositories, clone new remotes, configure SSH credentials, adjust font zoom, and view system diagnostic information.

📖 Git & Pragma-git Dictionary

Concept What it means in Pragma-git
Repository A project folder tracked by Git. Drop any folder onto Pragma-git to start tracking it.
Commit A permanent snapshot of your project at a specific moment in time with a descriptive message.
Store The single-click Pragma-git command that stages files, commits them, and pushes to remote.
Branch An independent timeline of commits. Keep clean code in main and work in feature branches.
Merge Combines two branches together. Overlapping file conflicts can be resolved with the merge tool.
Pull / Push Pull downloads changes from the cloud/server. Push uploads your local commits.
Stash Temporarily shelving uncommitted edits so you can pull, switch branches, or test cleanly.
HEAD The current revision or top commit of the branch you are actively working on.
Detached HEAD Looking at an old historical snapshot without being on a branch. Pragma-git guides you on safe branching.
